# نظام عادل الفقيه للتجارة العامة والاستيراد

نظام عربي RTL للمحاسبة والمبيعات وإدارة مخزون محل الأدوات المنزلية. الواجهة مبنية بـ React وTypeScript، والخادم Express، وقاعدة البيانات SQLite عبر `better-sqlite3`.

## تشغيل النظام

المتطلبات: Node.js 22.14 أو أحدث وnpm (يستخدم الخادم SQLite المدمج `node:sqlite`، ولا يحتاج إلى تثبيت مكتبة SQLite أصلية منفصلة).

```bash
npm install
npm run dev
```

افتح `http://localhost:3000`. عند التشغيل لأول مرة ستظهر شاشة إعداد حساب مدير النظام؛ أنشئ اسم المستخدم وكلمة المرور (6 أحرف على الأقل). لا يوجد حساب افتراضي أو كلمة مرور مكشوفة. يبدأ خادم API على المنفذ 8787 تلقائياً.

لإنشاء نسخة إنتاجية وتشغيلها:

```bash
npm start
```

يفتح التطبيق على المنفذ 8787 (يمكن تغييره بمتغير البيئة `API_PORT`). قاعدة البيانات SQLite تُنشأ تلقائياً في `data/adelfaqih.sqlite`. لتغيير موقعها عيّن `DB_FILE=/مسار/الملف.sqlite`.

## الوظائف

- لوحة مؤشرات بإيرادات اليوم والشهر، عدد الفواتير، المخزون والتنبيهات.
- إضافة الأصناف وتعديلها وحذفها، مع التصنيف والرمز وسعر التكلفة وسعر البيع والكمية.
- إصدار فواتير مبيعات باسم العميل وطريقة الدفع، مع خصم الكميات من المخزون والتحقق من توفرها.
- سجل فواتير وتقارير قابلة للطباعة، مع احتساب الربح الإجمالي اعتماداً على لقطة سعر التكلفة وقت البيع.
- إنشاء عدة حسابات وصلاحيات مدير/موظف، إيقاف الحسابات، وتغيير كلمات المرور.
- تخزين كلمات المرور بصيغة مشتقة آمنة، وجلسات دخول عشوائية مخزنة كقيم مجزأة.

## ملاحظات قاعدة البيانات والنسخ الاحتياطي

يحتوي مجلد `data` على قاعدة SQLite. انسخ ملف `data/adelfaqih.sqlite` احتياطياً بعد إيقاف الخادم، أو استخدم أدوات SQLite لأخذ نسخة متسقة أثناء تشغيله بسبب تفعيل WAL. لا ترفع قاعدة بيانات حقيقية تحتوي على بيانات حساسة إلى مستودع عام؛ الملف المرفق في حزمة المشروع قاعدة جديدة وفارغة.
