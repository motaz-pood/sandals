# نظام عادل الفقيه للتجارة العامة والاستيراد

نظام عربي RTL للمحاسبة والمبيعات وإدارة مخزون محل الأدوات المنزلية. الواجهة مبنية بـ React وTypeScript، وخادم البيانات Express، وقاعدة SQLite. يتوفر كتطبيق سطح مكتب Windows يعمل محلياً دون متصفح أو اتصال بالإنترنت، مع نسخة الويب للتطوير.

## تشغيل نسخة التطوير

المتطلبات: Node.js 22.14 أو أحدث وnpm.

```bash
npm install
npm run dev
```

افتح `http://localhost:3000`. عند التشغيل لأول مرة أنشئ حساب المدير وكلمة المرور (6 أحرف على الأقل). يبدأ خادم API محلياً على المنفذ 8787. ملفات خط Cairo والأيقونات محلية، ولا تعتمد واجهة النظام على تحميل موارد من الإنترنت.

## بناء تطبيق Windows المحمول (EXE)

على جهاز Windows أو بيئة بناء متصلة بالإنترنت، نفّذ مرة واحدة:

```bash
npm install
npm run pack:windows
```

ينشئ الأمر مجلد `release/Adel-Alfaqih-Offline` وملف ZIP بداخله تطبيق Windows المحمول بصيغة EXE، وأيقونة النظام، وقاعدة SQLite فارغة جاهزة. انقل المجلد إلى الجهاز المطلوب ثم شغّل `Adel-Alfaqih-Accounting.exe`. لا يحتاج الاستخدام اليومي بعد ذلك إلى الإنترنت أو المتصفح أو Node.js. يتطلب Windows 10/11 بنواة 64-bit.

احرص على إبقاء مجلد `data` بجانب EXE؛ ستُحفظ فيه قاعدة البيانات. التطبيق المحمول يختار مجلده تلقائياً، ويستمع لخدماته على واجهة loopback المحلية فقط. أنشئ حساب المدير عند أول تشغيل. خادم التطوير منفصل عن النسخة المحمولة.

> تنزيل ملفات Electron اللازمة لبناء EXE لأول مرة يتطلب اتصال الإنترنت على جهاز البناء. بعد اكتمال حزمة EXE تعمل على الجهاز المستهدف دون إنترنت.

## التشغيل الإنتاجي كخادم محلي

```bash
npm start
```

افتح `http://localhost:8787`. يمكن تغيير المنفذ بمتغير البيئة `API_PORT`. قاعدة البيانات الافتراضية في `data/adelfaqih.sqlite`؛ غيّر مسارها عبر `DB_FILE`.

## وظائف النظام

- لوحة مؤشرات بإيرادات اليوم والشهر، الربح الإجمالي، عدد الفواتير وتنبيهات المخزون.
- إضافة الأصناف وتعديلها وحذفها، مع التصنيف والرمز وسعر التكلفة وسعر البيع والكمية.
- إصدار فواتير مبيعات باسم العميل وطريقة الدفع، مع التحقق من المخزون وخصم الكميات تلقائياً.
- سجل فواتير وتقارير قابلة للطباعة، واحتساب الربح من تكلفة الصنف وقت البيع.
- حسابات متعددة بصلاحيات مدير/موظف، وإيقاف الحسابات وإدارة كلمات المرور.
- تخزين كلمات المرور بمشتقات scrypt ذات salt عشوائي، وجلسات دخول رمزية مجزأة.

## قاعدة البيانات والنسخ الاحتياطي

`installer-template/adelfaqih.sqlite` قاعدة ابتدائية فارغة مرفقة لبناء نسخة EXE. في التطبيق المحمول تُنشأ/تُستخدم قاعدة البيانات في `data/adelfaqih.sqlite` بجانب الملف التنفيذي. في التطوير الافتراضي هي `data/adelfaqih.sqlite` داخل المشروع. احتفظ بنسخة احتياطية من ملف SQLite، ولا تضع بيانات حقيقية حساسة في مستودع عام.
